# ENGINEERING LOG: Data & C++ (2026)

## Transition Goals: Analyst to Engineer
* Focus: Moving from "What happened in the data?" to "How do we build the pipe that moves the data?"
* Medallion Architecture:
    1. Bronze (Raw): The landing zone for messy, untouched data.
    2. Silver (Clean): Filtered, joined, and standardized data.
    3. Gold (Business): Aggregated data ready for a dashboard or an AI.

## C++ Learning Path (For Data Pipelines)
* Memory Management: In Python, I don't think about pointers. In C++, I have to be the manager. 
* Smart Pointers: Use `std::unique_ptr` and `std::shared_ptr` to avoid memory leaks. This is vital for high-performance data loading.
